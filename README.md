# 📚 Kitaab-e-Ghar — Kitab-e-Hikmat

> A multilingual digital knowledge workspace for reading books, solving real-life problems, learning from masterclasses, saving bookmarks, and teaching the system new books.

## 🌟 Overview

Kitaab-e-Ghar is an HMHS knowledge application centered on a living digital codex. It provides a book reader, searchable library experience, real-life problem solving, learning/masterclass workflows, user-taught books, bookmarks, multilingual UI, and document download features.

### ✨ Features

- 📖 Interactive book reader
- 🧠 Real-life dilemma/problem solver
- 🎓 Learning and masterclass workflow
- ➕ Teach the system new books
- 📚 Curated + user-added book library
- 🔖 Persistent bookmarks
- 🌐 English, Urdu, and Roman Urdu interface
- 📄 Word/PDF-oriented downloads
- 🤝 Book consultation between reader, solver, and teacher modes

## 🏗️ Core Architecture

```text
Book Library
    ↓
Reader ↔ Problem Solver ↔ Masterclass
    ↑            ↑              ↑
Bookmarks    User Books     Knowledge Ingestion
```

## 🛠️ Tech Stack

- React 19 + TypeScript
- Vite
- Express + Node.js
- Google Gemini via `@google/genai`
- Tailwind CSS
- Motion
- Lucide React
- jsPDF

## 🚀 Run locally

```bash
npm install
npm run dev
```

Production:

```bash
npm run build
npm start
```

Configure required AI/server environment variables through the project's environment configuration. Keep secrets out of Git.
